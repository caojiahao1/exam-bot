# exam-bot · 开卷答题助手

浏览器里的题库答题助手，**不需要安装任何浏览器插件**。

下载 → 双击启动 → 登录 → 开始答题。

## 原理

```
┌──────────────┐   CDP 注入   ┌─────────────────┐
│ 本地控制服务  │ ───────────▶ │  浏览器（考试页）│
│ :8778        │ ◀─────────── │  读题 / 勾选     │
└──────┬───────┘   HTTP 查询  └─────────────────┘
       │
┌──────▼───────┐
│ 题库 SQLite   │  严格模式：库里有才答，没有就留空
└──────────────┘
```

- 服务用 Chromium 的**远程调试协议**把答题脚本注入页面，所以不用装油猴
- 浏览器用**独立配置目录**启动（`~/.exam-bot-profile`），不碰你日常用的浏览器和登录态
- 答案只从本地题库取；**找不到就留空，绝不猜测**
- 脚本**永远不会点「交卷」**，最后一步由你确认

## 使用

### Windows

1. 安装 [Python 3](https://www.python.org/downloads/)（安装时勾选 *Add Python to PATH*）
2. 双击 `start.bat`
3. 浏览器自动打开控制台 `http://127.0.0.1:8778`
4. 点 **① 启动浏览器** → 在弹出的窗口里登录考试网站
5. 在同一个窗口打开有题目的考试页
6. 点 **② 注入脚本**，看到「题目块 N 个」就绪
7. 点 **③ 自动答题（整卷）**
8. 答完自己点交卷

### macOS / Linux

```bash
chmod +x start.sh
./start.sh
```

## 控制台按钮

| 按钮 | 作用 |
|---|---|
| 启动浏览器 | 用独立配置启动 Edge/Chrome，开调试端口 9222 |
| 注入脚本 | 把答题脚本注入当前页面 |
| 诊断 | 报告识别到几个题目块、有没有"下一题"按钮 |
| 自动答题（整卷） | 逐题作答 + 自动翻页，到最后一题停 |
| 暂停 / 继续 | 做完当前题停住 |
| 只答本页 | 只处理当前这一屏 |
| 停止 | 立即中断 |
| 关闭浏览器 | 只关本工具启动的那个实例 |

拟人节奏默认 **3–10 秒/题**，可切换「全速」。

## 题库

`data/bank.sqlite3`（SQLite，可用 DB Browser for SQLite 打开）

```sql
CREATE TABLE qa (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT,           -- 单选题 / 多选题 / 判断题
  stem TEXT,           -- 题干
  nkey TEXT UNIQUE,    -- 题干归一化指纹（去重）
  answer TEXT,         -- 答案：字母码 或 正确/错误 或 内容
  answer_letters TEXT,
  options TEXT,        -- 选项，分号分隔
  source TEXT,
  weight REAL DEFAULT 1.0
);
```

查询逻辑（`app/engine.py`）：

1. 题干归一化后**精确匹配** `nkey` → 命中
2. 否则算字符二元组 Jaccard 相似度，**≥ 0.85** 才采信
3. 都不过 → 返回空，页面上就留空

阈值在 `engine.py` 的 `STRICT_MIN`。

## 目录结构

```
exam-bot/
├── start.bat / start.sh      一键启动
├── app/
│   ├── server.py             本地控制服务（HTTP + 编排）
│   ├── engine.py             题库查询
│   ├── browser.py            浏览器启动/关闭
│   ├── cdp.py                CDP 客户端（零依赖）

```

## 常见问题

**点「启动浏览器」没反应 / 调试端口没开**
Edge/Chrome 新版不允许在*默认用户配置*上开调试端口，本工具已改用独立配置目录。若仍失败，先把该浏览器所有窗口关干净再试。

**注入后显示「题目块 0 个」**
说明当前页不是答题页，或页面结构没适配。点「诊断」看输出，把结果提 issue。

**浏览器窗口里没有登录态**
独立配置目录是全新的，第一次需要登录一次，之后会记住。

**题库怎么来的**
仓库自带一份基础题库；也可以把自己的题目按 SQL 或调用 `POST /api/bank/import` 导入。
